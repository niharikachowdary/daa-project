04 Where It Fails

The theorem needs constant a, constant b > 1, equally sized subproblems and a positive toll. These recurrences break one of those conditions.

Checklist: non-constant a · unequal splits · n − c instead of n / b · sub-polynomial gap · oscillating toll · log factors outside k ≥ 0.

Viva questions

State the three cases of the Master Theorem.

Let c = logb a. Case 1: f(n) = O(nc−ε) → Θ(nc). Case 2: f(n) = Θ(nc) → Θ(nc log n). Case 3: f(n) = Ω(nc+ε) plus regularity → Θ(f(n)).

Analyze Merge Sort with the Master Method.

T(n) = 2T(n/2) + Θ(n). Here a = 2, b = 2, log2 2 = 1 and f(n) = Θ(n1). Case 2 gives Θ(n log n) in best, average and worst cases.

Why is the regularity condition needed in Case 3?

It prevents an irregular or oscillating toll from breaking the geometric-sum argument. Formally a·f(n/b) ≤ c·f(n) for some c < 1. For f(n) = np it reduces to a / bp < 1, i.e. p > logb a.

Give a recurrence where the theorem fails.

T(n) = T(n/3) + T(2n/3) + n has unequal subproblem sizes; Akra–Bazzi gives Θ(n log n). T(n) = T(n−1) + n is decrease-and-conquer; iteration gives Θ(n²).

Standard versus generalized Master Theorem?

Standard Case 2 needs f(n) = Θ(nc) exactly. The generalized form allows f(n) = Θ(nc logk n), k ≥ 0, giving Θ(nc logk+1 n). Example: T(n) = 4T(n/2) + n² log n is Θ(n² log² n).
